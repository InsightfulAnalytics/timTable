# LEARNINGS

## 2026-07-07 — Pre-ship test pass (rename to Nexus Table)

- **Matrix rawValues are keyed in tree order INCLUDING subtotal leaves.** `columnLeaves` (display leaves) excludes subtotals, so any `colIdx * measureCount + mIdx` indexing into rawValues is wrong the moment a 2+ level Columns hierarchy exists (inner subtotal leaves interleave). Symptom: every value column after the first group boundary shows the previous tree slot's data — including the previous group's subtotal. The correct key is the tree index already tracked by `allColumnLeafIndex` during `flattenCol`. (visual.ts:2896/2933/3142/1432)
- **"All" series toggles must not force-resync on every update.** Row/Column Totals push the persisted `show*All` value onto every per-measure setting that differs, on every `update()` (visual.ts:2189-2204, 2353-2367). Any per-measure override is clobbered, and newly added measures always "differ" — this was the "totals randomly turn on" bug that couldn't be reproduced: it reproduces 100% of the time once you know the All dropdown state.
- **`Number(value)` coercion destroys text/date measures.** Matrix values can legitimately be strings or Dates; numeric NaN/Infinity from DAX arrive as **null** through the sandbox marshalling (so numeric 0/0 never shows "NaN" — it shows the blank placeholder), but text measures become literal "NaN" and Date measures render the raw format string. Type-check before coercing. (visual.ts:4000/5740)
- **Renaming a pbiviz visual (incl. GUID) requires a 6-point cascade** when a PBIP embeds it: pbiviz.json → rebuild → extract .pbiviz zip into `Report/CustomVisuals/<newGuid>/` (package.json + resources/<newGuid>.pbiviz.json) → report.json `resourcePackages` entry → every visual.json `visualType`. `pbir validate` + Desktop open verifies the cascade. GUID must be renamed BEFORE first AppSource submission — frozen afterwards.
- **`pbir desktop refresh -m` cannot re-apply a model containing a culture** (en-AU.tmdl) — Desktop rejects re-adding an existing culture. Model TMDL changes to this project require closing and reopening Desktop.
- **`pbir model -q` needs the report path argument** (`pbir model "Nexus Table.Report" -q "..."`) — without it the desktop connection is not resolved even when screenshots work.
- **Desktop marshals DAX NaN/Infinity to null** in the custom-visual dataview (JSON serialization) — a visual can't distinguish 0/0 from BLANK(); don't design UX that requires that distinction.
